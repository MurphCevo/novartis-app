# Summary of Deliverables

DLV = Deliverable

| # | Title | Description | Format | Maps to |
|---|---|---|---|---|
| DLV.001 | Knowledge Discovery Agent (UC-4) | Semantic search agent that retrieves approved assets, strategy docs, and campaign performance data from Novartis systems via intent-based natural language queries | Working software + technical docs | OBJ.001 |
| DLV.002 | Content Generation Agent (UC-5) | Agent that drafts compliant, publish-ready marketing content from approved templates and content blocks, with human-in-the-loop review and authoring tool integration | Working software + technical docs | OBJ.002 |
| DLV.003 | Asset Tagging Agent (UC-10) | Agent that automatically applies consistent metadata to assets based on content type, therapy area, audience, key message, and usage context, writing tags back to approved systems | Working software + technical docs | OBJ.003 |
| DLV.004 | Autopilot Assistant | Single natural-language chat interface through which marketers interact with all three PoC agents | Working software (chat UI) | OBJ.004 |
| DLV.005 | Integration Layer | API / MCP server connections to Novartis systems (VVPM, Aprimo/Fuse, SharePoint, Sherlock, Snowflake/CDH, SFMC, GA4, Veeva Oncore CRM, ShamanGo/Anthill Activator) | Working integrations + architecture docs | OBJ.005 |
| DLV.006 | Technical Architecture & Governance Documentation | End-to-end architecture design including CI/CD, LLM observability, RBAC, auditability, data security posture, and AI governance controls | Architecture docs (md / drawio / pdf) | OBJ.006 |
| DLV.007 | PoC Evaluation Report | Measurable outcomes against agreed quality, performance, governance, and end-user utility criteria  - supports the Go/No-Go decision on scale-up | Report (pdf / pptx) | OBJ.007 |
| DLV.008 | Knowledge Transfer Pack | Runbooks, operational documentation, and architecture handover materials to reduce ongoing vendor dependency | Documentation (md / Confluence) | OBJ.008 |

## Milestone Structure

Based on the 14-week / 7-sprint timeline discussed in planning sessions:

| Phase | Duration | Key Outputs |
|---|---|---|
| Phase 1  - Foundation | ~2 weeks | Infrastructure provisioned, landing zone confirmed, dev environment stood up, integration targets validated |
| Phase 2  - Agent Development | ~8 weeks | DLV.001 -003 built iteratively across sprints, integration layer (DLV.005) developed in parallel |
| Phase 3  - Assembly & Evaluation | ~4 weeks | DLV.004 (Assistant) assembled, end-to-end testing, DLV.007 (Evaluation Report) produced, DLV.008 (Knowledge Transfer) completed |

---

## Notes

- **Milestone-based payment**  - engagement is paid on milestone completion, not time-and-materials (per 2026-08-12 planning session).
- **Client dependencies**  - Novartis product owners provide APIs for source systems. Cevo integrates to them but does not build them.
- **DLV.006 is continuous**  - architecture documentation evolves throughout the engagement, not produced in a single drop.
- **DLV.007 is the Go/No-Go gate**  - its criteria must be agreed early (quality, governance, provenance, auditability, performance, end-user utility as per RFP §5d).
- **Phase 1 pre-requisites**  - model activation, account access, and environment provisioning are hard blockers before agent development begins (per ECH review 2026-08-20).
- **MSA not yet finalised**  - start date pushed from September 1; revised date TBD (per 2026-08-17 planning session).
