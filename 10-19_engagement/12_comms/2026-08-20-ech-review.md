## Summary

Session focused on identifying pre-requisites for standing up Agentic AI infrastructure at a client site. Model activation is a hard pre-req. The team identified the need for a repeatable "Project Readiness Checklist" covering organisational, technical, and data prerequisites. Novartis-specific questions were raised around service request processes, SLAs, access, and environment provisioning. Phase 1 target completion is 2 weeks from start date.

---

## Key Discussion Points

### Pre-requisites Identified
- Model activation is a pre-requisite before any work begins
- SES email may be needed if deploying email notifications
- Data residency requirements need clarification

### Novartis-Specific Process Questions
- How do we request new services?
- What is the process and SLA for requesting access / changes?
- What is the minimum set of infrastructure needed?
- What processes / forms / teams must be engaged to stand up a non-prod environment? What information is required?
- What is the whitelisting process for requesting a change to SCPs?
- Need access to Confluence and/or SharePoint
- What models are in use? How do we request new models?

### Ways of Working
- What is the SOP for tech work — client laptop or virtual desktop?

### Phase 1 Timeline
- Phase 1 completed date: **2 weeks from start date**

### Project Readiness Checklist (new practice artefact)
- Should cover:
  - Common requirements (applicable to any AI engagement)
  - Practice-specific requirements (project type dependent)
  - Organisational pre-requisites
  - Technical pre-requisites
  - Data schema for MCP and API integration
  - Integration routing and how it works
  - Day-one ask of the client
  - Teams that need to be engaged
