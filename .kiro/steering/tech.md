# Technical Context

## Project Type
Advisory / Consulting engagement (documentation-heavy, no application code)

## File Conventions
- Johnny Decimal numbering system for folder organisation
- Markdown for notes, meeting minutes, and deliverable drafts
- Draw.io for diagrams
- Excel/PowerPoint for client-facing deliverables

## Writing Style
- Professional consulting tone
- Clear, concise language
- Use headings and bullet points for readability
- Distinguish confirmed facts from working assumptions
- Label draft material explicitly
