## Interface Layer

| Field | Value |
|---|---|
| **Agent interface** | MCP server / Direct API / SDK / API Gateway / Manual (human relay) |
| **Underlying transport** | REST API / GraphQL / JDBC-SQL / File drop / Event stream / Webhook / Proprietary SDK |
| **Data format** | JSON / XML / CSV / Protobuf / Proprietary |

> **Agent interface** = how the agent discovers and invokes the capability.
> **Underlying transport** = how data physically moves between systems.
>
> These are separate concerns. An MCP server may wrap a REST API underneath. A direct API call skips the MCP layer entirely. Recording both surfaces the build effort (MCP server to create?) and the integration complexity (what protocol are we actually speaking?).
