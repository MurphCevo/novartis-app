# Interaction Patterns Register

## Purpose

This register documents how each AI agent interacts with each target system in the Novartis marketing technology landscape. It captures the interface layer, data characteristics, authentication model, readiness, and ownership for every system x agent combination - providing the integration team with a single source of truth for:

- **Architecture decisions** - which systems need MCP servers vs direct API calls vs an API gateway
- **Sprint planning** - sequencing integration work by readiness and risk
- **Dependency tracking** - surfacing what Novartis must provide before integration can begin
- **Discovery preparation** - giving product owner sessions a structured starting point so conversations focus on gaps, not basics

Each entry answers the question: *"Given what this agent needs to do with this system, what does the interaction look like, how ready is it today, and what do we need from Novartis to make it work?"*

---

> One entry per **system x agent** combination. All values inferred from RFP and planning sessions unless noted otherwise.
> Status: **Draft - assumed, not yet validated with Novartis product owners.**
